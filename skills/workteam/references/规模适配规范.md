# 规模适配规范

> 适用范围：一切 AI 协作工作开始前的定档。判据一句话：要不要开第二个会话。

## 1. 档位

- **单点档**：不需要第二个会话。一次修复、一个问答、一篇文档。
- **批量档**：需要会话并行或队列化处理，但人类可直接盯（无管控会话）。一批修复、一次支持值班、一套文档。
- **迭代档**：需要管控会话与多线并行（多仓/多边界/多外部依赖）。

## 2. 各档构件

| 构件 | 单点档 | 批量档 | 迭代档 |
| --- | --- | --- | --- |
| plan 批准 | 要 | 要 | 要（技术方案阶段） |
| 留言板 | 否 | 要 | 要 |
| 守望自驱动 | 否 | 要 | 要 |
| 管控会话 | 否 | 否（人类兼） | 要 |
| 决策台账 | 否 | 简表 | 全（DC/CC） |
| 独立核验 | 要 | 要 | 要 |
| 验收报告 | 否（排查报告即可） | 视交付 | 要 |

## 3. 升降档

- 批量档中发现跨仓/多边界依赖 → 升迭代档。
- 迭代档收尾期可降批量档节奏，但验收规范不降。
- 拿不准 → 就高不就低。
