# Workteam——多会话协作规程

一套让多个 AI 会话像团队一样替你干活的工作方式：你只做决策与验收；一个"总控"AI 会话（负责调度、不写业务代码）拆活、派活、查收成果；若干"线"会话（各自守着一个项目的独立 AI 会话）并行执行；全部沟通写在"留言板"文件上——任何会话挂了，进度和待办都不丢。

## 它给什么用、适合谁

适合一切"一个人盯不过来、又不想雇人盯"的多线工作：跨项目的开发迭代、一批问题修复、一次技术支持值班、一套文档编写。不适合的场景也会被自动照顾到——单个小修它会判"单点档"（不开第二个会话、不搞仪式）直接干。使用门槛：会跟 AI 会话对话即可，不需要懂规程内部实现。

## 使用前提

| 前提 | 要求 | 归属 |
| --- | --- | --- |
| AI 工具 | 已安装本技能（安装见下节） | 你的机器 |
| Python | ≥ 3.8（守望/等待脚本用，纯标准库） | 你的机器 |
| Node.js | ≥ 18（仅安装时 skills CLI 需要） | 你的机器 |
| git | 可用（规程文档与代码由 git 管理） | 你的机器 |

## 安装与开工

在终端执行下面的命令，选择 workteam：

```
npx skills add catcuts/agent-skills
```

装好后，你对任何一个新会话说一句人话（例："demo 系统有几处要修，改完给我列个清单"），或直接输入 `/workteam`。它会先问你四个问题（验收标准/涉及项目/外部依赖/时间窗），再给出方案请你批准——**未经你批准，它不动手**。
