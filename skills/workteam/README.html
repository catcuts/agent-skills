Workteam——多会话协作规程

Workteam 是一个装给 AI 会话用的技能包（skill，AI 工具的扩展）；它里面装的，是一套教多个 AI 会话像团队一样协作的规则——标题里的"多会话协作规程"，就是这套规则的名字。

为什么需要它？设想你有一摊跨几个项目的活——开发、修文档、联调。一个人开五六个聊天窗口来回切，很快会疯。装上这套规程后，你说一句"开工"：总控（负责调度的 AI 会话，不写业务代码）替你拆活、派活、查收成果；若干条线（每条线守一个项目的开发责任，由按批分配的临时 AI 会话干活）并行推进；它们的全部沟通与状态写在留言板、指令台账、线进度等文件上——任何会话结束或挂掉，进度和待办都不丢。你要做的只剩决策与验收。

本页是这套规程给人的说明书，按"认识角色 → 走一遍流程 → 亲手试玩 → 真实开工"的顺序展开，读下去即可；顶部导航可随时跳转。

本页为图解与演练；规则原文在技能的 references/ 目录，两者不一致时以规则原文为准（内容版本 v0.6.0）。

快速上手：装到自己机器上

模拟通关之后，把它装到你自己的机器上真实开工——四张卡片加一段示例对话，讲完全部步骤。

⓪ 使用前提

① 一个支持技能（skill）机制的 AI 工具，且已装好本技能（见右）；② Python ≥ 3.8（守望/等待脚本，纯标准库）；③ Node ≥ 18（仅安装时 skills CLI 需要）；④ git 可用（规程文档与代码由 git 管理）。

① 安装

在终端执行下面的命令，选择 workteam：

npx skills add catcuts/agent-skills
# 选择 workteam

② 说一句话

装好后，对任何一个新会话说一句人话（例见下方示意对话），或直接 /workteam。它会先问你四个问题（目标/涉及项目/外部依赖/时间窗），再给你方案请你批准——未经你批准它不动手。

③ 你的日常

之后你只跟总控对话：它每次回复末尾带「各线指令」区（每条线一个独立可复制的块）和发送时机表，你复制粘贴给各线即可；需要你拍板的事它会单独列出来。

规范§9-10契约先行与联调冻结窗口

契约先行＝先定协议/接口（能 mock、能校验、能处理异常）再开发；联调条件不齐→回流对应线补齐；联调期间其它线冻结。

规范§6长命令：傻等 vs 标志轮询

跑法一：sleep 10 分钟后去看输出
跑法二：wait_for.py 轮询结束标志
构建/编译/打包/部署一律后台执行＋结束标志轮询（输出/日志/接口响应），命中立即继续，只有超时才需要 AI 介入。禁止固定时长等待。

规范§3指令状态粒度：为什么线要"报到"

指令下发➜登记"开始 #N，时间"➜执行中…➜标记[已执行]
没有"开始"登记，管控看板上一片安静，只能误判"这条线还没动工"——真实项目里刚踩过的坑。

六个实验到此收束；演练场（正文第四节）里它们会以真实选择的形式再次出现。
