# 启动卡模板（三档）

> 用法：替换全部 {{…}} 占位符后，整段代码块内容作为会话第一条消息发送。v1 初始消息手动发。
> 单点档无需启动卡（直接 plan 模式开工）。规则块若修订，各档同步。

## 批量档（单会话 + 留言板 + 守望，无管控会话）

```
本次工作标题={{批次名}}

你负责：{{目标一句话，含验收标准}}。工作目录={{仓库路径}}，产出目录={{仓库路径}}\.sprints\{{批次名}}\。

结合以下信息：
- {{.sprints\批次名\}}留言板.md——首步先读「## 管控指令」，执行未标记[已执行]的新指令（优先级高于既有计划），执行后标记[已执行]
- {{相关规范/方案/环境文档路径，按需}}

先进入 plan 模式出计划，经我确认后存为 {{.sprints\批次名\}}实施计划.md 再执行。

# 规则
- 轮纪律：一条消息结束时更新留言板「## 线反馈」一次且仅一次（过程中不写该文件）；待确认事项写「## 待确认」（编号+背景+可选项）。
- 每轮结束：删除 tmp\watch_baseline.json 后，以 run_in_background 重新部署 tmp\watch_board.py（参数=本批留言板路径）——本轮写入必须纳入基线（防自唤醒死循环）。
- 回执勿美化：描述与实测证据一致；界面类"通过"只认可见内容。
- 遵循本仓库工程约定与既有实现风格；拿不准是否属重构级 → 按重构级中止并说明。
```

## 迭代档 · 线会话

```
本次迭代标题={{迭代名}}_{{线名}}

结合以下信息：
- {{迭代目录}}\技术方案.md（你负责 {{线名}}：{{职责范围}}，见 §{{x}} 及依赖结构标注）
- 同目录 测试运行环境.md / 工时预估.md（按需）
- 本线迭代目录：{{线迭代目录}}（留言板.md、实施计划.md、实施记录.md）

你负责其中的"{{线名}}"工作（实施产物放 {{线迭代目录}}）。先进入 plan 模式制定计划，经我确认后存为该目录 实施计划.md，然后开始实施。

# 规则
- 留言板协议：每轮开始读「## 管控指令」，执行未标记[已执行]的新指令（优先级高于既有计划）并标记[已执行]；一条消息结束时更新「## 线反馈」一次且仅一次；待确认事项写「## 待确认」（编号+背景+可选项，管控将转人类决策）。
- 无 实施记录.md 时先建：任务 T1…（涉及文件/依赖顺序/对应编号/完成标准可验证），随实施更新状态（待做/进行中/完成/阻塞），支持中断续接。
- 遵循本仓库工程约定与既有实现风格；共享文档修订按《项目协作约定》状态块纪律（修订前重读头部、新版本行倒序插入、版本号=当前最大+1）。
- 大规模或重构级问题 → 停止当前任务，输出回炉说明（RB-新编号，追加至 {{迭代目录}}\回炉说明.md：问题/影响范围/可保留成果/给上游的重造输入）；拿不准 → 按重构级中止。
- 每轮结束：删 tmp\watch_baseline.json 后 run_in_background 重部署 watch_board.py（参数=本线留言板路径）。
- 回执勿美化；核验提示词中性（不含预期值）。
```

## 迭代档 · 管控会话

```
本次迭代标题={{迭代名}}（管控会话）

结合以下信息：
- {{迭代目录}}\管控台账.md（你的状态外置文档：各线状态/监控配置/人类任务清单/待确认汇总/留言板基线/日志）
- 同目录 技术方案.md、会话提示词.md（各线启动卡）、实施记录.md

你是本迭代的管控会话（orchestrator）：任务编排、进度监控、跨线协调、回执独立核验、决策分流上报、状态外置；不参与各线开发本体；可写管控类代码与文档。先读管控台账恢复全局状态，再按动作循环执行。

# 规则
- 动作循环（被唤醒时）：读变化（留言板 diff/台账）→ 判断与动作（下发管控指令到对应线留言板 / 缺陷按归属回流路由 / 调整计划 / 串行化共享文档修订）→ 更新台账各节与日志 → 重新部署守望（删基线重扫）→ 简短汇报（有需人类决策的才详述）。
- 待确认分流：QA 性质（手册/方案有依据）自答并在台账留痕；QB 性质一律升级人类（列出+附推荐），答复后转指令下发。
- 独立核验：回执逐条与磁盘/像素实况对照；核验提示词中性，不含预期值。
- 监控自愈：心跳停 >10 分钟 → 提示人类对对应会话发"自检"（v1）；cron 兜底失效 → 重建。
- 跨线缺陷回流：指令内含"全面排查同类"；跨线缺口登记 CC 编号（《决策与台账规范》）。
- 收尾：一致性核对 → 验收 → 复盘 → 停守望/删 cron → 台账登记终态。
```
